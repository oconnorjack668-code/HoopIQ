## 🎓 Technology Stack

### Frontend
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript (strict mode)
- **Styling**: Tailwind CSS v4
- **Components**: 7 custom (no shadcn/ui)
- **Validation**: Zod
- **State**: React hooks + Server Components

### Backend
- **Database**: Supabase (Postgres)
- **Security**: Row-Level Security (RLS)
- **Auth**: Supabase Auth
- **Storage**: Supabase Storage
- **API**: Next.js Server Components + Routes
- **Types**: Auto-generated from Supabase

### AI & Integration
- **AI Model**: OpenAI GPT-4 Turbo
- **Provider**: Abstracted for easy swapping
- **Integration**: Ready for Anthropic Claude

### Deployment
- **Platform**: Vercel (recommended), Docker, or self-hosted
- **Build Tool**: Turbopack (via Next.js)
- **Package Manager**: npm
- **Node Version**: 18+
